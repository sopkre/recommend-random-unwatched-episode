# recommend-random-unwatched-episode
Flask application to get recommendations for a random episode to watch or listen to, constrained on episodes not finished for a while (or ever), based on logs of the content.

# Usage

Sourcing the start shell script
```
source start.sh
```
sets the database file and starts the flask application. It will tell you, where it is running, e.g. on http://127.0.0.1:5000 which you can access with your browser.

# Disclaimer

Be aware that this is application is not set up for actual production deployment, just for your own private use.
